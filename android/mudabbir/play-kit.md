# مُدبّر على Google Play

## 1) اعمل الباكدج من PWABuilder (من كروم بتاعك)
1. افتح https://www.pwabuilder.com واكتب: https://nrg1c3.github.io/mudabbir/
2. Package For Stores → Android → Generate Package → Options، وحط:

| الخانة | القيمة |
| --- | --- |
| Package ID | com.nrg.mudabbir |
| App name | مُدبّر |
| Launcher name | مُدبّر |
| App version | 1.0.0 |
| App version code | 1 |
| Host | nrg1c3.github.io |
| Start URL | /mudabbir/ |
| Theme color | #0F5552 |
| Background color | #0F5552 |
| Nav bar color | #0F5552 |
| Display mode | standalone |
| Notifications | شغّالة (Enable) |
| Signing key | New (جديد) |
| Key alias / names | Mudabbir / NRG |

3. Download، واحفظ الـ ZIP في مكان آمن. فيه ملف التوقيع (.keystore) والباسوردات: لو ضاع مش هتقدر تحدّث التطبيق تاني.
4. ابعتلي ملف assetlinks.json اللي جوه الـ ZIP بس (مش الـ keystore) عشان أضيف بصمته للموقع، وساعتها التطبيق يفتح من غير شريط المتصفح.

## 2) صفحة المتجر
- **اسم التطبيق:** مُدبّر: يومك وبيتك وفلوسك
- **الوصف القصير (80 حرف):** قولها بصوتك، ومُدبّر يرتّب يومك ويفكّرك بفواتيرك ومواعيدك.
- **الوصف الكامل:**

مُدبّر مساعد ذكي بالعامية المصرية. قول اللي في دماغك بصوتك، وهو يرتّبه لوحده: مهام ومواعيد وفواتير وحاجات ناقصة في البيت.

• منبّه بيرن والتطبيق مقفول، قبل كل ميعاد وفاتورة.
• ادفع فاتورتك من التذكير نفسه ببساطة أو فوري.
• البيت المشترك: قايمة واحدة لأهل البيت كله، مقفولة ومحدش يقراها غيركم.
• مود الأم، والولاد ودواهم ومواعيدهم، وموبايل طفل بسيط.
• بابا وماما: مكالمة كل يوم ودواهم، وشاشة كبيرة لموبايلهم.
• مود صاحب الشغل: الطلبات والتسليم والفلوس اللي برة والخزنة.
• الفلوس، الاشتراكات، الجمعية، العربية، المناسبات، والعادات.
• الصلاة والأذكار والقرآن لو حابب.

من غير حساب. بياناتك على موبايلك.

- **التصنيف:** Productivity
- **سياسة الخصوصية:** https://nrg1c3.github.io/Sanady/privacy.html?b=m
- **الصور:** icon-512.png (الأيقونة)، feature-graphic.png (1024×500). صور الشاشة: خد 4 من موبايلك (الشاشة الرئيسية، الفواتير والدفع، البيت المشترك، مود الشغل).
